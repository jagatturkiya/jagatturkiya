# Jagat Turkiya — Official Website

Official website for **Jagat Turkiya** — Global Transformation Coach, Author of 6 published books, Founder of Aapka Coach & Minderist Training LLP, and Times Square NYC featured mentor.

## 🚀 Features

- **Executive Aesthetic**: Premium monochrome dark architecture with tailored typography and subtle gold accents.
- **Responsive Layout**: Designed for seamless viewing across smartphones, tablets, and high-DPI desktop screens.
- **Pages**:
  - `index.html`: Main landing page featuring Jagat Turkiya's bio, leadership pillars, books, Times Square recognition, and consultation booking.
  - `about.html`: Biography, journey from humble beginnings to international recognition, and philosophy.
  - `media.html`: Media appearances, gallery, and Times Square billboard spotlight.
  - `books.html`: Catalog of published works (*Kill That Black Dragon*, *Nadar Riste*, *Asli Nayak*, *Anubhav Sagar*, *Book of Langotiya*, etc.).
  - `contact.html`: Consultation and contact inquiry form.

## 🛠️ Technology Stack

- **HTML5 & Vanilla CSS**: Zero bloat, responsive layout with modern CSS variables.
- **JavaScript**: Clean interactivity for forms and navigation.

## 💻 Local Development

To run the site locally:

```bash
# Using Python
python -m http.server 8000

# Or using Node.js / npx
npx serve .
```

Open [http://localhost:8000](http://localhost:8000) in your browser.
